# Caption style guide

**Stable ID:** `POLICY-CAPTION-STYLE-RECOMMENDED`

## Status

This policy is **recommended**.

## Recommendations

- Use captions for non-trivial images.
- Keep captions descriptive but concise.
- When helpful, link from the surrounding text to the figure anchor.
- Keep terminology aligned with the concept or feature page.
