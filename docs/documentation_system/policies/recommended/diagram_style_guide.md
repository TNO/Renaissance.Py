# Diagram style guide

**Stable ID:** `POLICY-DIAGRAM-STYLE-RECOMMENDED`

## Status

This policy is **recommended**.

## Recommendations

- Prefer SVG for diagrams.
- Keep labels concise.
- Use consistent terminology across diagrams and text.
- Prefer diagrams that remain readable in monochrome.
- Keep visual complexity proportional to the concept being explained.
