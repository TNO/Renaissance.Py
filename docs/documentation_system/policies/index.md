# Policies

Policies define constraints and conventions for the documentation system.

## Levels of strictness

1. [Mandatory policies](mandatory/index.md)
1. [Recommended policies](recommended/index.md)

## Interpretation

- **Mandatory** policies are intended to be enforced by tooling or explicit review.
- **Recommended** policies are strongly preferred but may rely more on editorial judgment.
